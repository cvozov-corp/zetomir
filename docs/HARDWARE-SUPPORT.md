# Поддержка оборудования

## Реализовано в текущем исходном дереве

| Компонент | Статус |
|---|---|
| x86_64 entry point | Есть |
| Limine BIOS configuration | Есть |
| Framebuffer | Базовый вывод при 32 bpp |
| COM1 serial | Инициализация и диагностический вывод |
| Limine memory map | Чтение и подсчёт usable memory |
| PS/2 keyboard | Не реализована |
| PS/2 mouse | Не реализована |
| USB HID | Не реализовано |
| ATA/AHCI/NVMe | Не реализовано |
| Ethernet/Wi-Fi | Не реализовано |
| Audio | Не реализовано |
| UEFI boot | Не подтверждён текущим ISO target |

## План реализации ввода

### Клавиатура
1. Настроить IDT и обработку аппаратных IRQ.
2. Инициализировать контроллер 8042, если он доступен.
3. Реализовать PS/2 scancode parser.
4. Добавить состояние Shift/Ctrl/Alt/Caps Lock и таблицу раскладки.
5. Организовать буфер/очередь событий ввода.
6. Подключить ввод к терминалу и графической среде.
7. Позже добавить USB xHCI и HID boot protocol.

### Мышь
1. Реализовать обработку IRQ контроллера.
2. Настроить PS/2 auxiliary device.
3. Собирать пакеты мыши и отслеживать синхронизацию.
4. Обрабатывать относительное движение, кнопки и колесо.
5. Добавить ограничение координат указателя границами framebuffer.
6. Передавать события в GUI input API.
7. Позже добавить USB HID mouse.

### Остальное оборудование
- Таймер: PIT как первый простой вариант; позднее APIC timer/HPET по необходимости.
- Диски: начать с виртуального блочного устройства в QEMU, затем AHCI/NVMe.
- USB: определить контроллер xHCI и реализовать перечисление устройств.
- Сеть: начать с виртуального адаптера QEMU, затем расширять список NIC.
- Звук: после базовой модели драйверов и прерываний.

## Политика совместимости

Для каждого драйвера фиксировать:
- поддерживаемые PCI ID/контроллеры;
- режим эмуляции и параметры VM;
- успешные и неуспешные тесты;
- реальные модели оборудования, проверенные вручную.

Нельзя заявлять «поддерживает USB» или «работает на любом ПК», если реализован только один частный путь.
