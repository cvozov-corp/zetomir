# Приложения Zetomir (host prototypes)

В этой версии добавлены две небольшие консольные утилиты. Они работают на Linux с Python 3 и пока **не являются приложениями, исполняемыми ядром Zetomir**.

## ZetoBrowse

Минимальный текстовый просмотрщик страниц HTTP/HTTPS:

```bash
./tools/zetobrowse https://example.com
./tools/zetobrowse
```

В интерактивном режиме вводите адрес или `q` для выхода. В конце страницы показывается список найденных ссылок. Прототип умеет:

- получать HTTP/HTTPS страницы;
- отображать текст из HTML и `text/plain`;
- скрывать содержимое `script`, `style`, `noscript` и SVG;
- выводить ссылки с номерами и абсолютными URL;
- ограничивать загрузку ответа 1 МБ и таймаут 12 секунд.

Ограничения: нет JavaScript, CSS-верстки, изображений, вкладок, cookies, истории, загрузок и полноценной поддержки HTML. Нумерованные ссылки пока только перечисляются — переход по ним не реализован. Не используйте прототип для авторизации, платежей или просмотра недоверенных сайтов с конфиденциальными данными.

## ZetoFetch

Краткая сводка системы в стиле fastfetch:

```bash
./tools/zetofetch
```

Показывает ОС, hostname, ядро Linux, архитектуру, CPU, использование памяти, uptime, shell, Python и терминал. Данные берутся из стандартных системных интерфейсов Linux (`/etc/os-release`, `/proc`). На других ОС часть полей может быть недоступна.

## Будущее в самой ОС

Для переноса внутрь Zetomir потребуются сетевой стек, DNS, TCP/IP, TLS, VFS и системные вызовы. Текущие Python-версии — рабочие прототипы интерфейса и поведения, а не нативные бинарные приложения Zetomir.
